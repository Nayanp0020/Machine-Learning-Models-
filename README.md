# Machine Learning Projects

Collection of basic Machine Learning projects built using Python, Scikit-learn and Google Colab.  
Includes classification, regression with datasets, outputs, and implementation notebooks.

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Projects Included
- Linear Regression
- Logistic Regression
- KNN Classification
- Decision Tree
- Random Forest
- Naive Bayes
- Support Vector Machine (SVM)

## Repository Structure
Each project folder contains:
- Jupyter Notebook (.ipynb)
- Dataset files
